# Inheritance - Python Programs

This folder contains separate runnable Python examples based on the uploaded OOP practical list.

## How to run
1. Extract the ZIP file.
2. Open the folder in VS Code or IDLE.
3. Open any `.py` file.
4. Run it using `python filename.py` in the terminal, or press Run in IDLE.

Python 3 is recommended. The abstraction examples use Python's built-in `abc` module.
