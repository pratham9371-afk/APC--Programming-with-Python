# Python Regular Expression Practicals

This repository contains 26 beginner-friendly Python programs based on regular expressions (`re` module).

## Requirements
- Python 3
- No external packages required

## How to run
Open a terminal in this folder and run an individual program, for example:

```bash
python 01_extract_digits.py
```

On some systems, use `python3` instead of `python`.

## Programs
1. Extract digits
2. Words starting with A/a
3. Count vowels
4. Extract uppercase letters
5. Find spaces, tabs, and newlines
6. Replace multiple spaces with one space
7. Find five-character words
8. Find words ending in s
9. Remove special characters
10. Count words
11. Validate a 10-digit Indian mobile number
12. Validate an email address
13. Extract dates in DD-MM-YYYY format
14. Extract HTTP/HTTPS URLs
15. Extract hashtags
16. Validate password requirements
17. Find consecutive repeated words (case-insensitive)
18. Extract six-digit PIN codes
19. Check a common Indian vehicle registration format
20. Extract file extensions
21. Remove HTML tags and clean text
22. Extract invoice numbers, dates, and monetary amounts
23. Identify full-line Python comments
24. Validate product codes in ABC-1234-XY format
25. Extract student names, roll numbers, and marks
26. Extract DOI identifiers, years, emails, and URLs

## Notes
- These are educational examples and use simplified patterns.
- A regex format check does not guarantee that a mobile number, email, date, vehicle registration, or PIN is officially valid.
- Program 23 identifies full-line comments; regex alone cannot reliably parse every Python string/comment edge case.
