# Python Class and Object Practicals

This repository contains 13 Python programs based on the class practical sheet.

## Requirements
- Python 3
- No external packages required

## Run a program
```bash
python 01_student_class.py
```

## Programs
1. Student details and percentage
2. Employee HRA, DA, and gross salary
3. Rectangle area and perimeter
4. Circle area and circumference
5. Display three books
6. Electricity bill using sample unit slabs
7. Mobile phone specifications and discount
8. Patient information and total bill
9. Menu-driven ATM
10. Vehicle rental
11. Shopping cart with constructor and destructor
12. Food order with tax and destructor
13. Student result with total, percentage, grade, and destructor

## Notes
- Salary percentages, electricity slab rates, tax rates, and grade bands are example assumptions for educational purposes. Adjust them if your instructor specifies different rules.
- The ATM example uses a sample account and balance; it is only a classroom simulation.
