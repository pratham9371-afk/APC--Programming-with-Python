# NumPy Practicals

This repository contains 25 Python programs based on the uploaded NumPy practical sheet.

## Requirements
- Python 3
- NumPy

## Install NumPy
```bash
python -m pip install numpy
```
If your system uses `python3`, run:
```bash
python3 -m pip install numpy
```

## Run a program
```bash
python 01_array_properties.py
```

## Programs
1. Array properties (size, data type, dimensions)
2. Arithmetic operations on arrays
3. Array statistics
4. Even and odd numbers using Boolean indexing
5. Reshape a one-dimensional array
6. Matrix addition
7. Matrix multiplication
8. Matrix transpose
9. Matrix indexing and diagonal
10. Row and column sums
11. Array slicing
12. Replace values using Boolean indexing
13. Sort in ascending and descending order
14. Unique elements
15. Horizontal and vertical concatenation
16. Student marks statistics
17. Marks above class average
18. Create a 3D array and inspect its properties
19. Access 3D array elements
20. Sums of a 3D array along axes
21. Replace values greater than 50 in a random 3D array
22. Statistics of a random 3D array
23. Flatten a 3D array
24. Statistics of a flattened 3D array
25. Filter a flattened random 3D array

## Notes
- Random-array programs may show different values each time.
- For 3D array sums, the code prints sums along each axis and labels the axes used.
