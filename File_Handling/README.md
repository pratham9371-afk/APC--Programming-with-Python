# Python File Handling, Modules, Packages and Directories Practicals

This repository contains beginner-friendly Python examples based on the uploaded practical sheet.

## Requirements
- Python 3
- No third-party libraries required

## Run
Open a terminal in this folder and run a file, for example:
```bash
python 01_write_student_file.py
```

Run package demos from the repository root so Python can find the packages. For example:
```bash
python 30_mathutils_package_demo.py
```

## Included
- File handling examples: create, read, append, count, search, replace, merge, compare files
- CSV-based student, employee, attendance, and transaction examples with sample CSV files
- Book-record menu program using `books.json`
- Module examples: calculator, student, number, string, salary, and recursive utilities
- Package examples: mathutils, student, banking, texttools, college project, library, ecommerce, and medical app

## Notes
- The electricity/account-like examples are educational only where applicable.
- Program 15 removes full-line Python comments; regex is not a complete Python parser and does not handle every `#` inside string literals.
- CSV and text programs expect the input files in the current working directory.
