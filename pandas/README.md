# Pandas Practicals

This repository contains Python programs based on the uploaded Pandas practical sheet.

## Requirements
- Python 3
- pandas

## Install pandas
```bash
python -m pip install pandas
```

## Run a program
For example:
```bash
python 01_student_dataframe.py
```

CSV analysis programs (13–16) expect their corresponding CSV files in the same folder.

## Contents
- Programs 01–07: DataFrames and data analysis
- Programs 08–12: Pandas Series
- Programs 13–16: Read and analyze CSV datasets
- Sample CSV datasets: students.csv, employees.csv, patients.csv, weather.csv

The records are sample data for learning and can be replaced with your own data.
